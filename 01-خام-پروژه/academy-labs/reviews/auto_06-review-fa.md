# شواهد بازبینی معنایی `auto_06` — مبانی REST API و Postman

تاریخ: ۲۰۲۶-۱۱-۲۷. **وضعیت بازبینی:** بازبینی معنایی توسط نویسنده (ایجنت)؛ **بازبینی مستقل انسانی انجام نشده است.**

- غلط تایپی آزمون قدیمی («چهخروجیی») رفع و تمام مفاهیم RFC 9110 / RFC 5789 (Safety، Idempotency، 204، 401/403، 429، Pagination) در ۱۴ بخش و ۱۲ پرسش تدوین شدند.
- فایل `01-خام-پروژه/academy-labs/agent3/auto_06_lab.py` یک سرور HTTP واقعی محلی روی `127.0.0.1` اجرا و متدهای CRUD را آزمون کرد؛ هیچ کنترلر بیرونی یا روتر واقعی متصل نشده است.

## بازبینی فنی فاز ۸C-1 (2026-11-27)
- **ایراد:** سرور محلی REST در `do_POST`/`do_PUT` با JSON ناقص کرش می‌کرد و POST تکراری را بی‌صدا بازنویسی می‌کرد.
- **منبع معتبر:** RFC 9110 (HTTP Semantics: 400 Bad Request, 409 Conflict, 201 Created, 204 No Content).
- **اصلاح انجام‌شده:** بازگرداندن `400 Bad Request` روی JSON نامعتبر/ناقص و `409 Conflict` روی POST تکراری + assertها.
- **تست مرتبط:** `test_phase8c1_automation_core_labs` در `01-خام-پروژه/tests/test_agent3_content.py`.
- **محدودیت:** سرور محلی `127.0.0.1` بدون کنترلر SDN خارجی؛ بازبینی نویسنده (نه مستقل).

## به‌روزرسانی فاز ۱۰E — خودبازبینی نویسنده (reviewed.9؛ بدون بازبینی مستقل انسانی)
- **تغییرات:** سخت‌سازی اعتبارسنجی VLAN ID در بازه [1..4094] (رد bool) و محدودسازی فیلدهای PATCH به `name`/`state` با پاسخ `400` در سرور HTTP Loopback.
- **وضعیت اجرا:** اجرای محلی Python بدون تجهیز شبکه یا سرویس بیرونی زنده؛ تطابق دقیق بایتی کد HTML با `auto_06_lab.py` تأیید شد.
