# auto_05 — بازبینی و ادغام انتخابی

منبع ایجنت سوم `1164394ccb10f823e1a0dd5321a168f64e3adb85`. بازبینی این نسخه و اصلاحات زیر توسط ایجنت یکپارچه‌ساز انجام شده، نه کارشناس مستقل انسانی. این به‌معنی تأیید سایر درس‌های ایجنت سوم نیست.

۱۴ بخش، مثال‌ها، تمرین‌ها، همه ۱۲ سؤال و ۴۸ گزینه و کد آزمایشگاه به‌طور موردی بررسی شدند. پاسخ‌ها به‌ترتیب تفاوت قالب‌ها، لودر YAML، مثال NO/on، JSON معتبر، tab در تورفتگی، namespace، خطر XML، قابلیت همکاری JSON/YAML، loads/dumps، تکرار کلید، schema و مرز آزمایشگاه هستند. سؤال هشتم برای پرهیز از ادعای بدون قید سازگاری همه پارسرها و سؤال نهم برای پذیرش مقدار scalar اصلاح شد. متن درباره tab در محتوای رشته، خطای احتمالی API، انواع SafeLoader، محدودیت منابع و علل متعدد نتیجه خالی XML دقیق‌تر شد. گواهی ایمنی کامل یا ارزیابی همه parserها نیست.

- [RFC 8259](https://www.rfc-editor.org/rfc/rfc8259) §۴ یکتایی نام‌ها را SHOULD می‌داند و §۶ NaN/Infinity را در دستور اعداد نمی‌پذیرد؛ رد تکرار نام‌ها سیاست سخت‌گیرانه اضافی است نه MUST نحوی. `json.loads` پیش‌فرض پایتون این ثابت‌ها را می‌پذیرد و آخرین مقدار کلید تکراری را نگه می‌دارد. محدودیت اندازه و دامنه اعداد باید مستقل بررسی شود؛ حتی متن عدد مجاز `1e400` در float پیش‌فرض پایتون ممکن است به infinity تبدیل شود.
- [YAML 1.2.2](https://yaml.org/spec/1.2.2/) استفاده از tab برای indentation را منع می‌کند، نه هر tab در کل فایل. [مستند PyYAML](https://pyyaml.org/wiki/PyYAMLDocumentation) درباره لودر ناامن و safe_load توضیح می‌دهد؛ safe_load جایگزین محدودیت منابع یا schema نیست. کتابخانه YAML در این آزمایشگاه استفاده نمی‌شود.
- [مستند امنیت XML پایتون](https://docs.python.org/3/library/xml.html#xml-vulnerabilities) خطرات مرتبط با parser، نسخه Expat و ورودی نامطمئن را بیان می‌کند؛ آزمایش با XML نمونه ثابت و مورد اعتماد است و ابزار تولیدی مقابله با ورودی غیرقابل اعتماد نیست.
- `tests/test_auto_05_integration.py` پارس محلی مثبت و منفی، NaN و دو Infinity، کلید تکراری تو در تو و انتخاب اختیاری last-wins، خروجی scalar، نمونه namespace و منطبق بودن کد داخل HTML را آزمون می‌کند. مثال‌های YAML صرفاً مدل محدود plain scalar هستند، نه پارسر؛ برای جلوگیری از تطبیق حروف نامعتبر و خروجی نقل‌قول شکسته مدل اصلاح شد. هیچ تجهیز، سرور شبکه، PyYAML، API تولیدی یا داده نامطمئن واقعی اجرا نشده است.
- ادغام با همان `lessonId` و `objectiveId` انجام شده؛ این خود انتقال یا مهاجرت داده پیشرفت از نسخه قدیمی نیست. در کاتالوگ به درس مستقلی تبدیل شده و HTML آفلاین از آن ساخته می‌شود. وضعیت و مرز اجرا در header و متن کارگاه آشکارند.
