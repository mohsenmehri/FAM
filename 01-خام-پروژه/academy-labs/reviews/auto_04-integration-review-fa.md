# بازبینی و ادغام انتخابی auto_04

منبع: `837fad64c25e2307675c576cad733ac0bdd99299`. بازبینی توسط ایجنت یکپارچه‌ساز، نه کارشناس مستقل انسانی. ۱۴ بخش، مثال‌ها و تمرین‌ها، تمام ۱۲ پرسش و گزینه‌ها، واژه‌نامه و برنامه بررسی شدند. در قیاس با نسخه قبلی، توضیح hash دیگر محرمانگی ادعا نمی‌کند؛ با این حال «تاریخچه تغییرناپذیر» را به توضیح اشیای محتوامحور و امکان بازنویسی اشاره‌گرها اصلاح کردیم. پاسخ revert را به نتیجه وابسته به تعارض و تغییرات بعدی محدود کردیم، branch protection را به تنظیمات و bypass مشروط و `.gitignore` را از تضمین مطلق خارج کردیم. قبل از همگام‌سازی شاخه مشترک بر بررسی status و fetch و تصمیم آگاهانه تأکید شد. [مستند gitignore](https://git-scm.com/docs/gitignore) و [git revert](https://git-scm.com/docs/git-revert) مبنای بررسی‌اند.

آزمایشگاه **باینری Git واقعی محلی** را با دستورهای ثابت و بدون shell در مخزن موقت اجرا می‌کند؛ Git 2.23+ و Python 3.10+ لازم‌اند. پس از بررسی، محیط فرایند به متغیرهای صریح محدود شد، پیکربندی global/system و template محیط بیرونی کنار گذاشته و مسیر hooks به دایرکتوری خالی هدایت شد؛ timeout اضافه و بررسی نادیده‌گرفتن فایل با `git check-ignore` دقیق شد. آزمون `tests/test_auto_04_integration.py` اجرای واقعی Git، سه commit، revert و بی‌اثر ماندن HOME/GIT_DIR و hooks خصمانه ارث‌رسیده را می‌سنجد. این sandbox سیستم‌عامل نیست و امنیت در برابر Git مخرب یا همه خطرات سیستم را تضمین نمی‌کند؛ برنامه فقط در محیط قابل اعتماد اجرا شود. هیچ remote، GitHub، Pull Request یا تجهیز شبکه واقعی در این تست تغییر نکرد. سناریوی دوم مرجع است و اجرا نشده. وضعیت در header و متن آنلاین/آفلاین روشن است.
