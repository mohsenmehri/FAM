## ۱. بررسی عمیق پاسخ‌های کوییز

### Q0: در شبکه‌های مدرن امروزی دارای لینک‌های `1Gbps` و `10Gbps`، چرا باید دستور `auto-cost reference-bandwidth 10000` (یا بالاتر) را روی همهٔ روترهای OSPF اجرا کرد؟
- **پاسخ انتخاب [3]:** چون با پیش‌فرض `100Mbps` تمام لینک‌های ۱۰۰ مگابیت و بالاتر Cost یکسان `1` می‌گیرند و تفکیک سرعت انجام نمی‌شود
- **توضیح:** اعداد کسری در Cost OSPF به ۱ گرد می‌شوند؛ بالا بردن Reference Bandwidth تفاوت سرعت‌های گیگابیتی و ده‌گیگابیتی را نمایان می‌کند.
- **وضعیت:** ✅ فنی صحیح

### Q1: کدام شرط برای برقراری همسایگی `FULL` در OSPF الزامی **نیست**؟
- **پاسخ انتخاب [0]:** یکسان بودن شماره Process ID (مثلاً هر دو `router ospf 1` باشند)
- **توضیح:** Process ID فقط یک شناسهٔ محلی درون خود آن روتر است و نیازی نیست روی دو روتر همسایه برابر باشد.
- **وضعیت:** ✅ فنی صحیح

### Q2: دستور `passive-interface Gi0/1` در پیکربندی OSPF چه اثری دارد؟
- **پاسخ انتخاب [1]:** شبکهٔ `Gi0/1` همچنان در OSPF تبلیغ می‌شود، اما روتر پیام Hello روی آن پورت نمی‌فرستد و همسایه‌ای از آن سمت نمی‌پذیرد
- **توضیح:** برای امنیت و جلوگیری از ترافیک اضافه، روی پورت‌های سمت کاربران از `passive-interface` استفاده می‌شود.
- **وضعیت:** ✅ فنی صحیح

## ۲. بررسی عمیق راه‌حل تمرین‌ها

### Ex0 (ساده)
- **مهمته:** اگر Reference Bandwidth روی تنظیم پیش‌فرض (`100 Mbps`) بماند، Cost دو اینترفیس `FastEthernet (100Mbps)` و `GigabitEthernet (1Gbps)` در OSPF چقدر حساب می‌شود؟ با تغییر Reference Bandwidth به `10000` (`10Gbps`) مقادیر جدید چه می‌شوند؟
- **راه‌حل:** در پیش‌فرض `100`: `100/100 = 1` و `100/1000 = 0.1 -> 1` (هر دو برابر و بدون تفاوت!). با تنظیم `10000`: FastEthernet برابر `10000/100 = 100` و GigabitEthernet برابر `10000/1000 = 10` می‌شود و مسیر گیگابیتی به درستی ترجیح داده می‌شود.
- **وضعیت:** ✅ موجود و فنی صحیح

### Ex1 (متوسط)
- **مهمته:** دستور یک Floating Static Route بنویسید که شبکهٔ `172.16.50.0/24` را از طریق Next-Hop پشتیبان `10.99.99.2` مسیریابی کند—به‌شرطی که فقط وقتی مسیر OSPF آن شبکه قطع شد فعال گردد.
- **راه‌حل:** `ip route 172.16.50.0 255.255.255.0 10.99.99.2 150`.
- **وضعیت:** ✅ موجود و فنی صحیح

### Ex2 (چالشی)
- **مهمته:** پیکربندی کامل `router ospf 1` را برای روتری با `Loopback0: 10.255.0.1/32`، لینک روتری `Gi0/0: 10.10.0.1/30` و شبکهٔ کاربران `Gi0/1: 192.168.10.1/24` بنویسید به طوری که: ۱) Router ID ثابت `10.255.0.1` باشد؛ ۲) محاسبه Cost برای لینک‌های تا ۱۰ گیگابیت دقیق باشد؛ ۳) به سمت شبکهٔ کاربران Hello نفرستد؛ ۴) روی لینک روتری `Gi0/0` از انتخاب بی‌دلیل DR/BDR صرف‌نظر کند.
- **راه‌حل:** `router ospf 1` -> `router-id 10.255.0.1` -> `auto-cost reference-bandwidth 10000` -> `passive-interface GigabitEthernet0/1` -> `network 10.10.0.0 0.0.0.3 area 0` -> `network 192.168.10.0 0.0.0.255 area 0` -> `network 10.255.0.1 0.0.0.0 area 0` -> `exit` -> `interface GigabitEthernet0/0` -> `ip ospf network point-to-point`.
- **وضعیت:** ✅ موجود و فنی صحیح
